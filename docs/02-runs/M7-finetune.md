# M7 — first fine-tune (run log)

Gate check: M6's scorecard ran before this started.

## What was trained

A QLoRA adapter teaching CBSE answer **format** — step structure, marks-
appropriate length, exam register. Deliberately not facts: syllabus content
changes yearly and varies by board, so it belongs in retrieval where it can be
swapped, not in weights where it can only be retrained out.

| | |
|---|---|
| Base | `unsloth/gemma-3-1b-it` (4-bit NF4, double-quantised) |
| Trainable params | 13,045,760 of ~1B (**1.2%**) |
| LoRA rank / alpha | 16 / 32, dropout 0.05 |
| Target modules | q, k, v, o, gate, up, down projections |
| Dataset | 500 generated examples, 450 train / 50 held out |
| Epochs / steps | 3 / 87 |
| Train runtime | 157.5s (8.6 samples/s) |
| Adapter on disk | 50 MB |

`google/gemma-3-1b-it` is a gated Hugging Face repo and returned 401 without a
licence acceptance. `unsloth/gemma-3-1b-it` is a public mirror of the same
weights and was used instead. If the team prefers the canonical repo, run
`huggingface-cli login` after accepting the licence.

Eval loss fell at every epoch alongside train loss, so this run is **not
overfitting yet**. Overfitting would show as train loss falling while eval loss
turns back up; a fourth epoch is where to watch for it.

## The number (exit gate)

Format adherence on the 40 held-out examples, judged by gemma3:12b, which never
saw the training run. Judge grades shape only, explicitly not facts.

| | base | adapter | delta |
|---|---|---|---|
| **overall** | **1.32/5** | **2.65/5** | **+1.32** |
| 1-mark (n=7) | 0.57 | 1.00 | +0.43 |
| 2-mark (n=11) | 0.82 | 2.00 | +1.18 |
| 3-mark (n=11) | 1.27 | 3.00 | +1.73 |
| 5-mark (n=11) | 2.36 | 4.00 | +1.64 |

The adapter beats the base, and improves in every marks bucket. It doubled
overall format adherence by training 1.2% of the parameters for 157 seconds.

## Honest caveats

The training data was generated by gemma3:12b, so the adapter is partly
distilling a larger model's formatting habits rather than learning genuine CBSE
marking-scheme conventions. Real marked answer scripts would be a better source.

The judge is gemma3:12b and the data generator was also gemma3:12b. That shares
a bias: the judge may reward the exact shape its sibling was told to produce.
An independent judge, or a human spot-check, would make this number more
trustworthy.

Absolute scores stay low (2.65/5) partly because 1-mark answers are graded
harshly — a single extra clause costs the mark. The delta is the trustworthy
figure here, not the level.
